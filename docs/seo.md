# קידום אורגני בגוגל — מה נבנה ומה נשאר לך לעשות

המסמך הזה מחולק לשניים: מה שכבר קיים בקוד ורץ בכל פריסה, ומה
שאי אפשר לעשות מהקוד וחייב להיעשות מהחשבון שלך.

---

## חלק א׳ — מה שכבר קיים

### כותרת ותיאור לכל עמוד

כותרת דף הבית הייתה `SetShifts` — שם שאיש אינו מחפש. עכשיו היא
`תוכנה לסידור עבודה ומשמרות לעובדים | SetShifts`, והיא סטטית
בקובץ עצמו ולא נוצרת בדפדפן. הנוסח יושב ב-`js/i18n/<שפה>.js`
תחת `landing.pageTitle` ו-`landing.metaDescription`, אחד לכל
שפה.

### שמונה שפות, שמונה כתובות

עד כה שמונה השפות היו קיימות רק בדפדפן: אותו קובץ נשלח לכולם
והטקסט הוחלף אחרי הטעינה. מבחינת גוגל זה היה אתר בעברית בלבד.

עכשיו הבנייה מייצרת עמוד לכל שפה, עם הטקסט כבר בתוכו:

| שפה | כתובת |
|---|---|
| עברית | `https://setshifts.com/` |
| אנגלית | `https://setshifts.com/en/` |
| ערבית | `https://setshifts.com/ar/` |
| גרמנית | `https://setshifts.com/de/` |
| ספרדית | `https://setshifts.com/es/` |
| צרפתית | `https://setshifts.com/fr/` |
| פורטוגזית | `https://setshifts.com/pt/` |
| רוסית | `https://setshifts.com/ru/` |

כל עמוד מצהיר על כל האחרים ב-`hreflang`, וגם מפת האתר מצהירה.
בורר השפה שבראש העמוד מעביר בין הכתובות, ולא מחליף טקסט במקום.

### נתונים מובנים

מה שהופך תוצאה רגילה בגוגל לתוצאה עם מחיר או עם רשימת שאלות
נפתחות:

- `Organization` ו-`SoftwareApplication` בדף הבית, כולל המחירון.
  המחירים נקראים מ-`js/backend/model.js` — אותו מקום שממנו
  נקרא המחירון באתר — כדי שלא ייווצר מצב שבו המחיר בגוגל אינו
  המחיר באתר.
- `FAQPage` ב"שאלות נפוצות" (27 שאלות) ובעמוד המחירים (5).
  השאלות נקראות מהעמוד עצמו בזמן הבנייה.
- `BreadcrumbList` בכל עמוד תוכן.

**אין `aggregateRating`.** דירוג מומצא אינו "שיפור SEO" אלא עילה
להסרה ידנית של האתר מהתוצאות. כשיהיו ביקורות אמיתיות אפשר
להוסיף — לא לפני.

### עמוד מחירים

`https://setshifts.com/pricing/` — "כמה עולה תוכנה לסידור עבודה"
היא שאילתה עם כוונת קנייה, והמחירון היה עד כה מקטע בתוך דף
הבית שאי אפשר לדרג אותו בנפרד. העמוד קיים בעברית ובאנגלית.

### מהירות בטלפון

התמונה הראשית היא אלמנט ה-LCP, ו-LCP הוא גורם דירוג ישיר
בחיפוש מהטלפון. הקובץ היה 1.3 מגה בכל מכשיר. עכשיו הוא מוגש
בארבעה רוחבים והדפדפן בוחר:

| רוחב | גודל | למי |
|---|---|---|
| 560 | 179 ק"ב | טלפון צר |
| 836 | 371 ק"ב | טלפון רגיל |
| 1100 | 620 ק"ב | טאבלט |
| 1672 | 1311 ק"ב | מסך רחב |

טלפון טיפוסי מוריד עכשיו 371 ק"ב במקום 1311 — פחות מרבע.

ליצירה מחדש אחרי החלפת התמונה:

```bash
npm run hero:sizes
```

### עוד דברים קטנים שתוקנו

- כל עמוד תוכן שלח `<link rel="manifest" href="undefined">`,
  כלומר כל ביקור ביקש מהשרת קובץ שאינו קיים וקיבל 404.
- כל העמודים הצהירו על אותה `og:url`, ולכן שיתוף של "שאלות
  נפוצות" בוואטסאפ הציג את דף הבית.
- `og:image` נשלח עם שתי מערכות מידות, ורשתות חתכו לפי השנייה.
- עמוד 404 אמיתי, במקום מסך ברירת המחדל של Vercel.
- `robots.txt` מרשה במפורש גם לסורקי בינה מלאכותית
  (GPTBot, PerplexityBot, ClaudeBot) — כדי שהמוצר יופיע גם
  בתשובות שאנשים מקבלים היום במקום לחפש.

### בדיקות

```bash
npm run test:seo
```

25 בדיקות שרצות על התיקייה הבנויה ולא על המקור: כותרות, שלמות
ההצהרה ההדדית של hreflang, תקינות ה-JSON-LD, התאמה בין המחיר
בנתונים המובנים למחיר במודל, שכל שאלה מסומנת באמת מופיעה
בעמוד, מפת אתר שכוללת כל עמוד שנבנה, ושאין דירוג מומצא.

## חלק ב׳ — מה שנשאר לך

אלה דברים שאי אפשר לעשות מהקוד. בלעדיהם האתר תקין טכנית אבל
גוגל לא בהכרח יודע שהוא קיים.

### 1. Google Search Console — הכי דחוף

בלי זה אתה עובד בעיוורון: לא תדע אילו עמודים נסרקו, אילו
שאילתות מביאות תנועה, ומה נכשל.

1. כניסה ל-https://search.google.com/search-console
2. הוספת נכס מסוג **Domain** (ולא URL prefix) — `setshifts.com`
3. גוגל יבקש רשומת TXT. מוסיפים אותה ב-Cloudflare תחת ה-DNS
   של הדומיין, בשם `@`, מסוג TXT.
4. אחרי האימות: **Sitemaps** → להדביק

```
sitemap.xml
```

5. **URL Inspection** → להדביק את `https://setshifts.com/` →
   **Request Indexing**. אותו דבר ל-`/pricing/` ול-`/faq/`.

### 2. Bing Webmaster Tools

עשרה אחוזים מהתנועה, וחמש דקות עבודה. הוא יודע לייבא הכול
מ-Search Console בלחיצה אחת:

https://www.bing.com/webmasters

### 3. פרופיל עסקי בגוגל

לעסק ישראלי שמוכר לעסקים ישראליים, זה מה שמופיע בצד ימין של
התוצאה כשמחפשים את שם המוצר, וזה גם מה שמופיע בחיפוש מקומי:

https://business.google.com

צריך שם עסק, קטגוריה (״ספק תוכנה״), אתר, טלפון ואזור שירות.

### 4. קישורים נכנסים

זה החלק שאין לו קיצור דרך, והוא מה שקובע בפועל כמה מהר מגיעים
לעמוד הראשון על שאילתות תחרותיות. דברים שעובדים לעסק בשלב הזה:

- רישום בספריות תוכנה ישראליות ובינלאומיות
  (Capterra, G2, GetApp, SourceForge, AlternativeTo).
  כולן חינם לרישום בסיסי, וכולן נותנות קישור.
- פוסט אחד בלינקדאין ובקבוצות פייסבוק של בעלי עסקים, עם
  קישור לעמוד המחירים ולא לדף הבית.
- כל לקוח פיילוט שמסכים — בקשה לאזכור.

### 5. תוכן, בקצב שאתה יכול לעמוד בו

האתר מכסה היום את השאילתות המסחריות (״כמה עולה״, ״מה זה עושה״,
״האם אפשר לסמוך״). מה שחסר הוא השאילתות שאנשים מחפשים *לפני*
שהם יודעים שקיים מוצר כזה. כל אחת מאלה היא עמוד:

- איך בונים סידור עבודה שבועי בלי אקסל
- חוק שעות עבודה ומנוחה — מה מותר בסידור משמרות
- מנוחה בין משמרות: כמה שעות חייבים
- דוח שעות לרואה חשבון — מה חייב להופיע בו

אלה עמודים שצריך לכתוב נכון פעם אחת, לא למלא במילות מפתח. אם
תרצה, אפשר לבנות אותם באותה תבנית של עמודי התוכן הקיימים.

---

## מה לא לעשות

- **לא לקנות קישורים.** זה עובד לשבועיים ואז מוריד את האתר.
- **לא לשכפל את דף הבית לשמונה עמודים עם מילות מפתח שונות.**
  זה מה ש-hreflang בא למנוע, וגוגל מזהה את זה מיד.
- **לא להוסיף דירוג כוכבים לנתונים המובנים לפני שיש ביקורות
  אמיתיות.** יש בדיקה שמונעת את זה בקוד, והיא שם בכוונה.

## לוח זמנים מציאותי

דומיין חדש לא עולה לעמוד הראשון בשבוע, וכל מי שמבטיח אחרת מוכר
משהו. מה שכן קורה:

| מתי | מה |
|---|---|
| 3–7 ימים אחרי Search Console | דף הבית מופיע בחיפוש `setshifts` |
| 2–4 שבועות | כל העמודים מאונדקסים, שאילתות ארוכות מתחילות להביא כניסות |
| 2–4 חודשים | דירוג על שאילתות בינוניות (״תוכנה לסידור משמרות לעסק קטן״) |
| 6–12 חודשים | תחרות על ״סידור עבודה״ ו״סידור משמרות״ — תלוי בעיקר בקישורים ובתוכן, לא בקוד |

הצעד היחיד שמזיז את השורה הראשונה מ״אף פעם״ ל״השבוע״ הוא
Search Console. כל השאר יכול לחכות.
