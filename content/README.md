# content/ — הטקסט של עמודי התוכן

בתיקייה הזו יושב הטקסט של חמשת עמודי התוכן — `about`, `stories`,
`pricing`, `faq`, `contact` — קובץ אחד לכל עמוד ולכל שפה:

```
content/faq/he.html      /faq/
content/faq/en.html      /en/faq/
content/faq/de.html      /de/faq/
...
```

המסגרת (לוגו, לשוניות, בורר שפה, כותרת תחתונה) יושבת פעם אחת
ב-`page.html` שבשורש, ו-`build-site.js` מרכיב את שניהם לכל צירוף.

## מה יש בקובץ

הקובץ הוא הגוף הפנימי של `<article>` — בלי התגית עצמה. בראשו
הערה עם שתי שורות חובה:

```html
<!--
  title: שאלות נפוצות
  description: מחיר, תקופת ניסיון, ומה קורה בסוף.
-->
<h1>שאלות נפוצות</h1>
```

`title` נכנס ל-`<title>` עם `· SetShifts` בסוף, ו-`description`
לתגית התיאור ולתצוגה המקדימה בשיתוף. שניהם נכתבים בשפת הקובץ: הם
מה שאדם קורא בתוצאת החיפוש לפני שהוא מחליט אם ללחוץ.

## שלושה כללים

1. **קובץ חסר עוצר את הבנייה.** אם נוספת שפה ל-`tools/seo.js`
   ולא נוסף לה קובץ, הבנייה נכשלת בשם הקובץ החסר. זה מכוון:
   כתובת שמוצהרת ב-hreflang ואינה קיימת היא 404 שעוצר סריקה.

2. **הקישורים נכתבים בעברית ומתורגמים בבנייה.** בתוך הטקסט כותבים
   `/contact/`, ו-`seo.localizeLinks` הופך אותו ל-`/de/contact/`
   בעמוד הגרמני. עמוד משפטי (`/privacy/`) מקבל `#en` במקום קידומת,
   כי הוא עברית ואנגלית באותה כתובת.

3. **`{{SUPPORT_EMAIL}}`, `{{LEGAL_ENTITY}}`, `{{LEGAL_ID}}`
   ו-`{{LEGAL_ADDRESS}}`** מוחלפים בבנייה ממשתני הסביבה. סימון
   שנכתב בשם אחר יישאר בעמוד כמו שהוא.

## מה לא נמצא כאן

העמודים המשפטיים — `privacy`, `terms`, `security`, `accessibility`
— ובנוסף `guide` (המדריך לעובד). אלה נשארו קבצי HTML בשורש, עם
עברית ואנגלית באותה כתובת ובורר בתוך העמוד (`js/legal.js`).
מסמך משפטי מתורגם בלי שעורך דין קרא אותו הוא התחייבות שאיש לא
בדק, והצהרת נגישות היא הצהרה על תקנות ישראליות שאינה חלה על
מבקר מגרמניה.

## מה נבדק אוטומטית

`npm run test:seo` בודק, לכל חמישה עמודים כפול שמונה שפות: שהעמוד
נבנה, שה-hreflang הדדי ומפנה לעמוד המקביל ולא לדף הבית, שהקישור
הקנוני מצביע על עצמו, שה-h1 אינו בעברית בשפה שאינה עברית, שכל
הקישורים נשארים באותה שפה, שהלשונית הנכונה מסומנת פעם אחת, ושכל
שמונה הגרסאות הן שמונה טקסטים שונים — כלומר שאף תרגום לא נשכח
כעותק של האנגלית.

`npm run test:pages` בודק את אותם עמודים בדפדפן: בורר השפה, טופס
יצירת הקשר, והלשוניות בטלפון.
