# סרטון ההדגמה

אזור "ראו איך בונים סידור שבועי בדקה וחצי" בדף הבית מנגן את
הקובץ שיושב כאן.

| קובץ | מה זה |
|------|-------|
| `setshifts-demo-he.mp4` | הסרטון עצמו. **עוד לא הועלה.** |
| `poster.png` | תמונת הפתיחה. נוצרת מהלוגו ב-`npm run icons`. |
| `setshifts-demo-he.vtt` | כתוביות בעברית. |

## להעלות סרטון

1. לשמור את הקובץ כאן בשם **`setshifts-demo-he.mp4`** בדיוק.
2. לעדכן את הזמנים והטקסט ב-`setshifts-demo-he.vtt` כך שיתאימו לו.
3. לדחוף. Vercel בונה מחדש, והנגן נדלק מעצמו.

עד שהקובץ קיים, האזור מוצג עם תמונת הפתיחה ועם הודעה שהסרטון
בדרך — ולא עם כפתור Play שמוביל לשום מקום.

## מה שכדאי לשמור עליו

- **עד 1:30.** זה מה שכתוב בכותרת, וזה מה שאנשים מוכנים לתת.
- **H.264 ב-MP4**, 1280×720 או 1920×1080. זה מה שכל דפדפן מנגן
  בלי תוסף.
- **עד 20 מגה.** הסרטון אינו נטען עד שלוחצים, אבל מי שלוחץ
  ממתין — וברשת סלולרית 40 מגה זה נצח.
- **קול לא חובה.** הסרטון אינו מתנגן אוטומטית, ולכן אין בעיה
  של קול פתאומי. אבל הכתוביות כן חובה.
